# m5-hw5-wilson-tiffany
Module 5 Accessibility Audit Assignment

## Accessibility Audit
I used the WAVE Web Accessibility Evaluation Tool to audit the website and identify accessibility issues.

## Issues Identified and Fixes
- Added visible labels associated with the name, email, and message form fields.
- Corrected heading levels to create a logical heading structure.
- Added semantic navigation and main content landmarks.
- Updated text and background colors to improve contrast and readability.
- Preserved the original website content while making accessibility improvements.

## Testing and Results
After making the corrections, I tested the website again using WAVE. The final evaluation reported 0 errors, 0 contrast errors, 0 alerts, and an AIM score of 10/10.


## Conclusion
This assignment helped me better understand the importance of semantic HTML, accessible form labels, color contrast, and keyboard navigation.
